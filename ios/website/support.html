Setup and troubleshooting

Zelmux Support

Basic setup

  1. Start the Zellij web server on your Mac or server.
  2. Create a Zellij web authentication token.
  3. Open Zelmux and enter your server URL, token, and session name.
  4. Use the session picker to attach to an existing session or create a new one.

Connection checklist

  • Confirm your iPhone or iPad can reach the server URL.
  • Confirm the token is a Zellij web token and has not expired or been removed.
  • Confirm the target Zellij session has web sharing enabled.
  • If a certificate prompt appears, verify the fingerprint before trusting it.

Common fixes

If sessions do not appear, restart the Zellij web server and refresh the session picker. If a session appears but does not attach, enable web sharing for that session from Zellij on the Mac.

Need help?

Use the support contact listed in the App Store listing. Include your Zellij version, device model, iOS version, and the error shown in Zelmux.

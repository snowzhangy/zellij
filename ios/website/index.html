Zellij on iPhone and iPad

Remote terminal access for your Zellij sessions.

Zelmux connects to your own Zellij web server so you can monitor agents, switch sessions, paste prompts, and keep work moving from a mobile device.

Built for agent sessions

Quick access to slash commands, prompt composition, session switching, and terminal controls that are hard to type on a phone.

Your server, your data

Zelmux connects only to the Zellij server URL you configure. Tokens stay in the iOS Keychain and are not sent to the app developer.

Lightweight terminal UI

Focus mode, scroll gestures, font controls, and iPad support keep the terminal usable on small and large screens.

Requirements

  • A Mac or server running Zellij with the web client enabled.
  • A Zellij web authentication token created on your server.
  • Network access from your iPhone or iPad to that server.
